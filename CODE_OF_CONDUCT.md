# Code of Conduct

This project adopts the **Contributor Covenant** (version 2.1) as its code of
conduct. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Summary

- Be welcoming, respectful, and constructive in all project spaces
  (issues, pull requests, discussions, and any related communication).
- Focus on the technical substance; disagree without being disagreeable.
- Give credit where it's due.

## Scope

This applies within all project spaces and when an individual is representing
the project in public.

## Enforcement

Reports of unacceptable conduct can be sent to **saurabh.chaubey17@gmail.com**.
All reports will be reviewed promptly and in good faith. Confidentiality will
be respected.

See the Contributor Covenant link above for the full enforcement guidelines
and definition of acceptable/unacceptable behavior.
